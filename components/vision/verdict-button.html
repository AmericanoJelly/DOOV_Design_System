Usage

  • 한 번에 하나만 선택됩니다.
  • 적록 색각이상을 고려해 항상 글자를 함께 표시합니다.
  • 추론이 끝나기 전에는 비활성으로 둡니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<div class="dds-verdict">
  <button class="pass" aria-pressed="true">적합</button>
  <button class="fail" aria-pressed="false">부적합</button>
  <button class="hold" aria-pressed="false">보류</button>
</div>
