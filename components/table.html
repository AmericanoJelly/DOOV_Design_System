Usage

  • 숫자 열은 오른쪽 정렬, 글자 열은 왼쪽 정렬합니다.
  • 판정은 Badge(점 + 글자)로 표시합니다.
  • 헤더는 스크롤해도 위에 고정합니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<div class="dds-table-wrap">
  <table class="dds-table">
    <thead><tr><th>No.</th><th class="num">Score</th><th>판정</th></tr></thead>
    <tbody>
      <tr><td>1</td><td class="num">0.71</td><td><span class="dds-badge dot danger">부적합</span></td></tr>
    </tbody>
  </table>
</div>
