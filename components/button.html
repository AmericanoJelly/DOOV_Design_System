Button

사용자가 어떤 행동을 실행할 때 누르는 기본 버튼입니다.

DraftLast updated 2026-11-21

Preview

Primary 버튼에 마우스를 올려 보세요. 테두리만 있던 버튼이 채워집니다.

Variants

종류쓰임
Primary화면에서 가장 중요한 행동 하나 (예: 추론 시작, 저장)
Secondary함께 놓이는 보조 행동 (예: 취소, 파일 업로드)
Tertiary눈에 덜 띄어야 하는 행동 (예: 초기화)
Ghost툴바·목록 안의 가벼운 행동
Danger되돌리기 어려운 행동 (예: 삭제, 일괄 부적합)

Specs

항목값토큰
높이32 / 40 / 48px (Small / Medium / Large)--control-sm / md / lg
좌우 여백12 / 16 / 20px
모서리8px(Small) · 12px--radius-sm / md
글자14px · 600--font-size-secondary
아이콘16px · 글자와 6px 간격
Primary그라데이션 테두리 1.5px + Purple 글자 → hover 시 그라데이션으로 채움 + 흰 글자--gradient-primary-border · --gradient-primary
Secondary흰 표면 + 1px 테두리--color-surface · --color-border
비활성회색 표면 + 흐린 글자--color-surface-muted · --color-text-disabled

Usage

  • Primary 버튼은 한 화면(또는 한 카드)에 하나만 둡니다.
  • 버튼 문구는 동사로 짧게 씁니다. (예: "확인" 대신 "저장")
  • 처리 시간이 걸리면 로딩 상태로 바꾸고 중복 클릭을 막습니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<button class="dds-btn primary">추론 시작</button>
<button class="dds-btn secondary">취소</button>
<button class="dds-btn danger">일괄 부적합</button>
<button class="dds-btn primary sm">Small</button>
<button class="dds-btn primary is-loading"><span class="dds-spinner"></span>추론 중</button>
