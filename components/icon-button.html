Icon Button

아이콘만으로 행동을 나타내는 버튼입니다. 툴바나 좁은 공간에서 씁니다.

DraftLast updated 2026-11-21

Preview

Variants

종류쓰임
Default배경 없이 아이콘만
Outlined흰 표면 + 테두리, 독립적으로 놓일 때
Active토글된 상태 (예: 격자 보기 켬)

Specs

항목값토큰
크기32 / 40px--control-sm / md
아이콘16 / 20px
모서리8 / 12px--radius-sm / md
색기본 아이콘 · hover 시 진해짐--color-icon-subtle → --color-icon
ActivePurple 아이콘 + 회색 면--color-icon-primary · --color-action-selected

Usage

  • 반드시 aria-label(웹) 또는 툴팁으로 이름을 붙입니다.
  • 의미가 분명한 아이콘에만 씁니다. 애매하면 Text Button을 씁니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<button class="dds-icon-btn" aria-label="확대">…svg…</button>
<button class="dds-icon-btn outlined" aria-label="다운로드">…svg…</button>
<button class="dds-icon-btn is-active" aria-label="격자 보기">…svg…</button>

C# Desktop

WPF / WinForms 중 구현 방식이 정해지면 작성합니다. 그 전까지는 위 Specs의 크기·색 토큰을 기준으로 구현합니다.
