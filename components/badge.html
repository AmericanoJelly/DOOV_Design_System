Badge

상태나 분류를 짧게 표시하는 라벨입니다.

DraftLast updated 2026-11-21

Preview

기본 신규 적합 부적합 주의 안내 v2.3 12

Variants

종류쓰임
Default중립 분류 (회색 면)
Dot상태 표시 — 점 + 상태색 글자
Outline버전, 태그처럼 흰 배경이 필요할 때
Count알림 개수 (Purple 그라데이션)

Specs

항목값토큰
높이24px (Count 20px)
모서리완전한 둥근 형태--radius-full
글자14px · 600 (Count 12px)--font-size-secondary
배경회색 면--color-bg-subtle
상태색글자·점에만 사용--color-{status}-text

Usage

  • 상태는 색만으로 구분하지 않고 글자를 함께 씁니다.
  • 배지 안 글자는 2~4글자 정도로 짧게 씁니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<span class="dds-badge">기본</span>
<span class="dds-badge dot success">적합</span>
<span class="dds-badge dot danger">부적합</span>
<span class="dds-badge count">12</span>

C# Desktop

WPF / WinForms 중 구현 방식이 정해지면 작성합니다. 그 전까지는 위 Specs의 크기·색 토큰을 기준으로 구현합니다.
