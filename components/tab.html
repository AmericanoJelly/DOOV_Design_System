Tab

같은 화면 안에서 영역을 나눠 전환합니다.

DraftLast updated 2026-11-21

Preview

Variants

종류쓰임
Line페이지 안의 영역 전환 (밑줄)
Pill상단 헤더의 주요 메뉴 전환 (검사 / 이력)

Specs

항목값토큰
Line 글자16px · 600--font-size-body
Line 밑줄2px Purple 그라데이션--gradient-primary
Pill 높이32px--control-sm
Pill 선택Purple 그라데이션 + 흰 글자--gradient-primary
미선택 글자--color-text-assistive

Usage

  • 탭 이름은 명사 한두 단어로 짧게 씁니다.
  • 탭이 많아 넘치면 Dropdown으로 바꿉니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<div class="dds-tabs line" role="tablist">
  <button class="dds-tab" role="tab" aria-selected="true">검사</button>
  <button class="dds-tab" role="tab" aria-selected="false">이력</button>
</div>

C# Desktop

WPF / WinForms 중 구현 방식이 정해지면 작성합니다. 그 전까지는 위 Specs의 크기·색 토큰을 기준으로 구현합니다.
