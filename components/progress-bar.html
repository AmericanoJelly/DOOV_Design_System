Progress Bar

추론, 업로드처럼 시간이 걸리는 작업의 진행 상황을 보여줍니다.

DraftLast updated 2026-11-21

Preview

추론 진행1 / 5
모델 불러오는 중
업로드 실패3 / 10

Variants

종류쓰임
Determinate진행률을 알 때 (1 / 5)
Indeterminate끝을 알 수 없을 때
Error실패 — 빨간 막대 + 문구

Specs

항목값토큰
트랙 높이6px--color-surface-muted
막대Purple 그라데이션--gradient-primary
라벨14px, 숫자는 600 + 자릿수 정렬--font-size-secondary

Usage

  • 가능하면 "1 / 5"처럼 남은 양을 숫자로 보여줍니다.
  • 1초 안에 끝나는 작업에는 표시하지 않습니다.

Web

tokens.css와 components.css를 불러온 뒤 아래처럼 씁니다.

<div class="dds-progress">
  <div class="head"><span>추론 진행</span><b>1 / 5</b></div>
  <div class="track"><div class="bar" style="width:20%"></div></div>
</div>
